## 🇬🇧 English
Userscript that fixes YouTube video preview sizes in the desktop feed.

### Installation
1. Install a userscript manager: Tampermonkey / Violentmonkey / Greasemonkey.  
2. Create a new userscript and paste the code from `youtube.js`.  

---

## 🇷🇺 Русский
Userscript для исправления размеров превью YouTube-видео в десктопной ленте.

### Установка
1. Установите менеджер userscriptов: Tampermonkey / Violentmonkey / Greasemonkey.  
2. Создайте новый userscript и вставьте код `youtube.js`.
